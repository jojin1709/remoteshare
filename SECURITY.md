# Security Policy

## Supported Versions

RemoteShare actively receives security updates and vulnerability patches:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security and integrity of RemoteShare very seriously. If you believe you have discovered a security vulnerability or exploit in RemoteShare:

1. **Do not disclose publicly**: Please refrain from opening a public GitHub Issue.
2. **Contact Directly**: Reach out privately to **JOJIN JOHN** via GitHub ([@jojin1709](https://github.com/jojin1709)) or create a private vulnerability report via GitHub Security Advisories.
3. **Include details**: Provide a clear description, reproduction steps, proof of concept (PoC), and potential impact.

### Response Timeline
- **Acknowledgement**: Within 24 hours.
- **Triage & Assessment**: Within 48 hours.
- **Patch & Advisory Release**: Expedited critical fixes deployed within 72 hours.
